# Example report

Open `index.html` directly in your browser. Keep this entire folder together.

This report was generated by the pipeline from synthetic DNA (seed 20260910). It includes 64 chromatin molecules split between two physical index pairs and 32 Micro-C molecules.

Explore library size profiles, sublibrary tables, genomic coverage, custom BED uploads, ligation structure and MNase evidence. `assets/chromatin.custom_regions.bed` contains two regions on the synthetic reference and can be uploaded in the chromatin report.

All figures and downloadable report data are included. Raw FASTQ, reference sequences and calculation intermediates are not part of this example. Input paths in the provenance are portable labels for the generated test data.
